# 当前实施决定（2026-09-28）

以下结论覆盖本文后面的早期讨论：用户已授权 Rust 实现，并要求先更新架构，新增 mac-cli 作为主要控制和调试入口；mac 为兼容入口。个人使用、Codex 引擎、全局最多 20 个执行 worker、保留 /sh、删除 /notify。

用户消息指导当前工作；Agent query 建立配置副本并复用 collaboration_id 的多轮上下文。请求方接收结果并决定是否继续；被查询方使用所属 Bot 身份。模板版本、协作会话和 cron 配置快照分开管理。CLI、聊天与 scheduler 共用持久化应用层。

实施契约见 [CLI 控制面](../cli-control-plane.md)，实际完成状态和限制见 [README](../../README.md)。下文保留历史决策过程，原有“尚未授权实现”表述已被本次授权覆盖。
